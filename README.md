# SOAR + EDR Incident Response Automation 🚨

📌 Project Overview

A cybersecurity project that automates **security alert detection, notification, and incident response** using **Wazuh EDR, Tines SOAR, Slack, HTTP/API, and PowerShell**.

🎯 Objectives

* Automate security alert handling
* Reduce manual SOC work
* Improve incident response time
* Integrate EDR with SOAR
* Automate security notifications

🛠️ Technologies

`Wazuh` `Tines` `Slack` `HTTP/API` `PowerShell` `Kali Linux` `VMware`

🔄 Workflow

Security Event
      ↓
Wazuh EDR
      ↓
HTTP/API
      ↓
Tines SOAR
      ↓
Alert Processing
      ↓
Slack Notification
      ↓
Automated Response

🔐 Key Features

* Security event monitoring
* Automated alert processing
* Wazuh–Tines integration
* Slack notifications
* Incident response automation
* PowerShell response actions
